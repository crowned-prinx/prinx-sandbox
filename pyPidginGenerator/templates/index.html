Pidgin Generator API Documentation

Welcome to the Pidgin Generator API Version 1.0. This API translates English text into Pidgin.

Base URL

https://api.princesunny.org

Endpoints

1. Get API Info

Endpoint: /gen-pidgin

Method: GET

Description: Returns a welcome message (this webpage) with API usage instructions.

    GET / HTTP/1.1
    Host: https://api.princesunny.org/gen-pidgin

2. Translate to Pidgin

Endpoint: /gen-pidgin/translate

Method: POST

Request Body: JSON

    {
        "text": "Hello, how are you?",
        "style": "informal"  // Optional: 'informal' or 'formal'
    }

Response: JSON

    {
        "pidgin_text": "How far, how you dey?"
    }

Error Handling

  • 400 Bad Request: If the "text" field is missing or empty.
  • 400 Bad Request: If "style" is not 'informal' or 'formal'.
  • 500 Internal Server Error: If the translation fails.
